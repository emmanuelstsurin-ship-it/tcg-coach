# Skill : Digestion

**Mission** : faire en sorte que le business puisse « digérer » plus de clients sans casser — et sans que l'entrepreneur s'épuise.

## Déroulé

### 1. Identifier le type de problème
- **Capacité** : l'entrepreneur est saturé, ne peut pas prendre plus de clients.
- **Qualité** : erreurs, retards, plaintes.
- **Rétention** : les clients partent avant d'avoir obtenu le résultat.
- **Équipe** : recrutement raté, équipe qui ne délivre pas.

### 2. Capacité → audit du temps et délégation
1. Faire lister toutes les tâches d'une semaine type, avec le temps passé.
2. Classer chaque tâche :
   - **Valeur** pour le business (haute / basse).
   - **Plaisir / talent** de l'entrepreneur (haut / bas).
3. Ordre de délégation : basse valeur + bas talent d'abord → automatiser ou déléguer. Garder : haute valeur + haut talent (souvent vente, offre, vision).
4. Estimer : combien d'heures libérées, combien ça coûte, combien ces heures rapportent si réinvesties sur le bottleneck.

### 3. Qualité → process (SOP)
Pour chaque tâche répétitive critique :
- Écrire une SOP simple : objectif, déclencheur, étapes numérotées, check-list de qualité, exemple de résultat attendu.
- Méthode rapide : s'enregistrer en vidéo en faisant la tâche, puis faire transcrire et structurer par BOS.
- Dépose les SOP dans `Output/SOP_nom-de-la-tâche.md`.

### 4. Rétention → résultat client
- Quel est le résultat que le client attend ? Combien l'obtiennent vraiment ?
- Quand les clients partent-ils ? Pourquoi ? (Demander aux 5 derniers partis.)
- Leviers : onboarding fort (première victoire en semaine 1), points de contact réguliers, suivi de progression, communauté, attentes claires dès la vente.
- Métrique : churn mensuel, % de clients qui atteignent le résultat.

### 5. Recrutement
1. Process documenté **avant** de recruter.
2. Fiche de poste par résultats attendus (« gérer 100 % du support client avec < 4 h de délai de réponse »), pas par tâches.
3. Sourcing : réseau, plateformes freelance, clients satisfaits.
4. Test payant court sur une tâche réelle.
5. Période d'essai avec objectifs chiffrés.
6. Commencer freelance / temps partiel avant un CDI.
Règle : recrute lentement, sépare-toi vite.

### 6. Rythme
Proposer un système minimal : réunion hebdo de 30 min, tableau de bord de 5 métriques, revue mensuelle.

## Mise à jour des fichiers
- `Core/Business.md` : équipe, outils, capacité, churn.
- `Core/Actions.md` : délégation / SOP / recrutement priorisé.
- `Output/` : audit du temps, SOP, fiche de poste.
